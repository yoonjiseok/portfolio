# Portfolio

AX 개발자 포트폴리오 페이지입니다. 빌드 과정 없이 `index.html` 한 파일로 동작합니다.

## 라우팅 시연

첫 화면의 입력창에 질문을 적으면 아래 순서로 처리되는 모습을 그래프로 보여 줍니다.

1. 입력이 오케스트레이터로 들어갑니다.
2. 오케스트레이터가 질문의 의도를 읽고 담당 에이전트와 비중을 정합니다.
3. 경력, 프로젝트, 기술, 수상과 활동, 연락 에이전트가 각자 맡은 내용에서 답을 만듭니다.
4. 결과를 합쳐 화면에 보여 줍니다.

이 시연은 브라우저 안에서 도는 규칙 기반 라우터입니다. 실제 모델을 호출하지 않으므로 API 키가 필요 없고, 정적 호스팅에서 그대로 동작합니다.

## 내용 수정

`index.html` 아래쪽 스크립트의 첫 번째 구역에 있는 값만 고치면 페이지와 에이전트 응답이 함께 바뀝니다.

| 값 | 내용 |
|------|------|
| `PROFILE` | GitHub 주소, 메일 주소 |
| `EXPERIENCE` | 경력 |
| `PROJECTS` | 프로젝트. `keys`는 라우터가 이 프로젝트를 찾을 때 쓰는 낱말 |
| `SKILLS` | 기술 |
| `AWARDS` | 수상과 활동 |
| `EXAMPLES` | 입력창 아래 예시 질문 |

## 배포

GitHub 저장소의 Settings, Pages에서 Source를 `main` 브랜치의 루트로 지정하면 됩니다.
